# Goodreads

> Goodreads is the world's largest site for readers and book recommendations, letting members catalog books, rate and review them, track reading, and get personalized recommendations. It is an Amazon company. Goodreads operated a public developer API (XML, developer key + OAuth 1.0a) that it began retiring on 2020-12-08 — new developer keys are no longer issued and there is no current public API. This llms.txt is generated by the API Evangelist enrichment pipeline from the network catalog; Goodreads does not publish its own.
